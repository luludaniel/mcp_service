# 계약서 검토 체크리스트 예시

실제 `POST /api/contract-review` 응답의 `nextSteps`/`policy.warnings` 필드를 그대로
옮긴 정적 예시입니다(2026-08-01, mock provider). 백엔드가 이 문서를 생성하거나
저장하지는 않습니다 — `legal-harness/outputs/reports/contract-review-report-example.json`이
원본 응답입니다.

## 예시 입력

> 계약 문구: "공급자는 언제든 계약을 해지할 수 있고 고객은 남은 대금을 모두 부담합니다."
> 당사자 지위: 고객

## 검토 진행 체크리스트 (`nextSteps`)

- [ ] 일방적이거나 모호한 조항을 식별합니다.
- [ ] 법률 및 거래상 위험을 우선순위로 정리합니다.
- [ ] 협상 쟁점과 대체 문구를 초안 제안으로 준비합니다.

## 식별된 위험 (`mockResult`, 참고용)

- 위험도: **high**
- 일방적 해지 또는 대금 부담 위험
- 책임 배분 범위가 과도할 가능성

## 사용 전 확인 사항 (`policy.warnings` + `policy.disclaimers`)

- [ ] 이 결과는 최종 법률 판단, 승소 보장, 위법 단정으로 사용할 수 없습니다.
- [ ] 계약 문구 변경안은 서명 또는 전달 전에 전문가 검토가 필요합니다.
- [ ] 출처 확인 필요 — 인용된 법령/판례를 원문으로 재확인합니다.
- [ ] 근거가 부족한 단정적 분석은 제한됩니다.
- [ ] 준거법과 당사자 지위를 다시 한번 확인합니다.
