# 문서 초안 체크리스트 예시

실제 `POST /api/document-draft` 응답의 `nextSteps`/`mockResult.deliveryChecklist`/
`policy.warnings` 필드를 그대로 옮긴 정적 예시입니다(2026-08-01, mock provider).
백엔드가 이 문서를 생성하거나 저장하지는 않습니다 —
`legal-harness/outputs/drafts/document-draft-example.md`가 이 요청으로 만든 초안
예시입니다.

## 예시 입력

> 문서 유형: 지급 요청서
> 사실관계: 거래처가 두 차례 독촉 후에도 청구서 2026-001 금액을 지급하지 않았습니다.
> 수신인: 거래처

## 초안 작성 진행 체크리스트 (`nextSteps`)

- [ ] 필수 사실관계와 첨부자료를 확인합니다.
- [ ] 누락된 정보는 임의로 작성하지 않고 자리표시자로 남깁니다.
- [ ] 사용 전 인용과 절차 요건을 확인합니다.

## 발송 전 체크리스트 (`mockResult.deliveryChecklist`)

- [ ] 수신인 신원과 주소를 확인합니다.
- [ ] 근거 자료를 첨부합니다.
- [ ] 기한과 발송 증빙 요건을 확인합니다.

## 사용 전 확인 사항 (`policy.warnings` + `policy.disclaimers`)

- [ ] 이 결과는 최종 법률 판단, 승소 보장, 위법 단정으로 사용할 수 없습니다.
- [ ] 생성된 문서는 초안이며 제출, 서명, 발송 전에 전문가 검토가 필요합니다.
- [ ] 출처 확인 필요 — 인용된 법령/판례를 원문으로 재확인합니다.
- [ ] 근거가 부족한 단정적 분석은 제한됩니다.
